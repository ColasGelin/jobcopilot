The flow

  1. Change a prompt, a model or the scoring rules.
  2. Run the evaluation: here, or jobcopilot eval run --gate (exits 1 when blocked).
  3. Read the verdict, then the failing cases.
  4. Promote the run to baseline when it is better; undo the change when it is blocked.
  5. Keep using the dashboard: every job you apply to or skip becomes a new test case.
